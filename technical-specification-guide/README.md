# technical-specification-guide v0.3.0

Purpose:

Create detailed technical architecture guides that humans can understand **without simplifying away the technical substance**.

Key v0.2 changes:
- Golden Master Preservation Mode
- Reader Value Rule
- Narrative Continuity
- Conceptual Expansion Budget
- No Silent Architecture Invention
- Semantic Propagation Audit
- Normative Strength Preservation
- Publication Cleanliness
- Direct Artifact Acceptance Review
- Publication QA

The v0.2 philosophy is deliberately more restrained than v0.1:
do less rewriting, preserve more information, and require the final document to be demonstrably better than the preferred source.
