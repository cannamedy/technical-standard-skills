# Activation Examples

## Strong trigger
- "把这份详细技术规范改得第一次接触的人也能读懂，但不要删技术内容。"
- "这是我最喜欢的版本，基于它增强解释，不要推倒重写。"
- "审查这份架构白皮书到底是不是人真的能读懂。"
- "保留原文细节和案例，只修叙事、术语和理解障碍。"

## Use Golden Master Preservation Mode
- "这版是黄金母版。"
- "我最喜欢这一版。"
- "基于这一版继续演进。"
- "不要把原来的好内容弄丢。"

## Do not treat as this skill's primary job
- exact JSON Schema generation;
- normative clause formalization;
- conformance test IDs;
- wire protocol definition.

Those belong to engineering-contract-spec.
