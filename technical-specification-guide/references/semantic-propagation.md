# Semantic Propagation Audit

When a core term changes, search the whole document.

## Audit targets

- title/section headings;
- definitions;
- diagrams;
- tables;
- object names;
- field names;
- examples;
- mock implementations;
- questions;
- conclusions.

## Example

If Physical Node may contain multiple Devices, inspect:
- Device Identity;
- device_id;
- Node Identity;
- Manifest ownership;
- reference nodes;
- capability ownership;
- discovery identity.

A local clarification is incomplete until dependent language is reconciled.
