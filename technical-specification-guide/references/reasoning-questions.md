# Architecture Reasoning Questions

Questions should test architecture understanding rather than vocabulary recall.

Good dimensions:
- boundary;
- authority;
- semantics;
- capability ownership;
- lifecycle;
- safety;
- discovery;
- state vs event;
- reference profile vs standard.

## Good distractors

A distractor should be technically plausible but violate one architecture principle.

Avoid obviously absurd answers that can be rejected without understanding the system.

## Consistency

Questions must use the same canonical terms as the body.
Do not introduce new formal semantics only inside a question.
