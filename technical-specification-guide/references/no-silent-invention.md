# No Silent Architecture Invention

Teaching prose must not decide unresolved architecture.

## Common accidental inventions

- converting discovery concepts into a strict lifecycle;
- turning examples into mandatory ordering;
- defining Node cardinality without a decision;
- making a reference profile mandatory;
- forcing all actions into one operation model;
- assigning capability computation to a layer because the diagram needs a box.

## Safe responses

- explain the concept without over-specifying;
- label the example as illustrative;
- state that exact semantics are defined elsewhere;
- identify an open design question during authoring/review.

Never invent a rule just to make a diagram prettier.
