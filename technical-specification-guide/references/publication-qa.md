# Publication QA

Check:
- section numbering continuity;
- figure numbering order;
- table numbering order;
- figure/table references;
- heading hierarchy;
- duplicate headings;
- canonical terminology;
- code/example consistency;
- physical quantity names;
- broken cross-references;
- accidental internal-process language.

A document can pass content checklists and still feel unfinished if publication QA is weak.
