# Narrative Continuity

Human readers understand systems through causal progression.

## Strong progression

Existing architecture
→ solved problem
→ remaining problem
→ new abstraction
→ consequence
→ next problem

## Weak progression

Definition
→ table
→ example
→ slogan
→ new definition
→ table
→ example
→ slogan

The second pattern may be locally clear but globally fragmented.

## Review method

Read several pages continuously.

Ask:
- Does each section create the reason for the next section?
- Are headings interrupting a story that should remain prose?
- Are tables replacing explanation?
- Are repeated "mental model" summaries necessary?
- Can two neighboring micro-sections be merged into one coherent argument?

Prefer continuous prose where the engineering reasoning is continuous.
