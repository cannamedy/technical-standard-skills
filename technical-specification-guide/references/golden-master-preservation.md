# Golden Master Preservation

When a user prefers an existing document, assume that preference reflects real value in:
- information coverage;
- writing rhythm;
- technical depth;
- examples;
- organization;
- terminology.

Do not assume a new structure is better.

## Preservation hierarchy

1. Architecture meaning
2. Technical information
3. Canonical terminology
4. Valuable examples/counterexamples
5. Narrative rhythm
6. Layout/formatting

## Omission ledger

For each meaningful deletion:
- source section;
- removed idea;
- reason;
- replacement location;
- risk of lost context.

If no strong reason exists, restore it.
