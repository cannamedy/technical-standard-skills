# Open Contract Issue

Use an `OPEN CONTRACT ISSUE` when the architecture or contract leaves a load-bearing behavior
undecided. The implementation agent must not resolve it by assumption.

```markdown
## OPEN CONTRACT ISSUE OCS-001

- Source Principle / Section: 
- Affected Requirements: 
- Missing Decision: 
- Why implementation cannot safely infer it: 
- Downstream Tasks Blocked: 
- Proposed Options: 
- Resolution Status: OPEN
```

An issue blocks only the affected behavior when its scope is known. Record its resolution in the
authoritative Contract before reopening blocked planning or coding work.
