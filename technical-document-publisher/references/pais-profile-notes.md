# PAIS Publication Notes

For a PAIS architecture guide, a suitable default direction is:

- formal technical-white-paper tone;
- A4;
- restrained cover;
- automatic TOC;
- Heading 1/2/3 hierarchy;
- stable Chinese/English mixed fonts;
- monospaced ASCII diagrams;
- compact technical tables;
- page numbers;
- simple header/footer;
- no editing-process language.

Do not include phrases such as:
- human-readable edition;
- golden master;
- generated by AI;
- Skill-generated document.

The publication should talk about PAIS, not its writing workflow.
