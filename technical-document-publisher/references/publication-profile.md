# Publication Profile

Keep presentation decisions separate from body content.

Typical fields:

```yaml
document:
  title: ...
  version: ...
  status: ...

page:
  size: A4
  margins: ...

body:
  font: ...
  size: ...
  line_spacing: ...

headings:
  numbering: true

toc:
  enabled: true
  depth: 3

code:
  monospace: ...

header:
  enabled: true

footer:
  page_numbers: true
```

Do not store rewritten technical paragraphs in the publication profile.
