# Technical Standard Skills

Reusable, Agent-neutral Skills for technical standard architecture, engineering contracts, implementation planning, contract-driven coding, and publication workflows.

包含五个 Skill：

- technical-specification-guide v0.3.0
- engineering-contract-spec v0.3.0
- contract-implementation-planner v0.1.0
- contract-driven-coding v0.1.0
- technical-document-publisher v0.3.0

版本：

- technical-specification-guide v0.3.0
- engineering-contract-spec v0.3.0
- contract-implementation-planner v0.1.0
- contract-driven-coding v0.1.0
- technical-document-publisher v0.3.0

推荐工程链：

```text
Architecture / Design
        ↓
Engineering Contract
        ↓
Implementation Planning
        ↓
Contract-Driven Coding
        ↓
Verification
```

Publication 是旁路能力：approved technical content 可以交给
`technical-document-publisher` 发布为 DOCX/PDF，不是 Coding 的必经步骤。

推荐安装方式：

```text
clone repository
→ run install.sh
→ symlink into ~/.agents/skills/
```
