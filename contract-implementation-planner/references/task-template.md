# Atomic Task Template

Use this as a minimum contract for each durable task file. Adapt wording to the repository without
removing the authority and verification anchors.

```markdown
# TASK-001: Short objective

## Objective

## Implements
- REQ-...

## Authoritative Contract Anchors
- Contract: `path/to/contract.md#section`
- Requirement: `REQ-...`

## Dependencies

## Current State

## Required Behavior

## Inputs / Outputs / Failures

## Files Allowed / Expected

## Files / Areas Forbidden

## Test / Verification

## Acceptance Criteria

## Definition of Done

## Open Contract Issues
- None, or list issue IDs and the blocked behavior.
```

`Files Allowed / Expected` is the implementation plan's file map. It is not a new normative
requirement in the Engineering Contract.
