# Generic Question Examples

These examples are domain-neutral illustrations of item quality, not answer keys for a particular
project.

## Weak item

**Stem:** What should an interface contract define?

- A. The semantic boundary and failure behavior
- B. Banana
- C. A random color
- D. Music

This item is invalid as an assessment because three distractors are not plausible and reveal the
answer through absurdity.

## Stronger item

**Stem:** A transport adapter successfully converts messages between two protocols, but consumers
still disagree about what the message means. Which conclusion is best supported?

- A. The adapter should own all domain semantics.
- B. A transport conversion alone does not establish a shared semantic contract.
- C. The consumer should infer semantics from field names.
- D. The transport should be replaced before semantics are defined.

The distractors model wrong layer, implicit semantics, and premature replacement. The stem provides
one discriminating problem and the correct proposition follows from the stated facts.
