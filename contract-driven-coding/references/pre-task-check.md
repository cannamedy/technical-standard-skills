# Pre-task Check

Before editing code, record:

- Task path and Task ID;
- Implements Requirement IDs / Section Anchors;
- Contract path, version, and referenced sections;
- current repository and Git state;
- dependency outputs available;
- allowed / expected files;
- forbidden areas;
- test and verification method;
- known open issues and whether they block this Task.

If any load-bearing input is missing or contradictory, stop with `OPEN CONTRACT ISSUE`, `PLAN / TASK
DEFECT`, or `PLAN EXPANSION REQUIRED` as appropriate.
